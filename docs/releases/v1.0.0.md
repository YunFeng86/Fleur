# Fleur v1.0.0

<!-- update-notes:en -->
- Redesigned the main workspace with a cleaner sidebar, adaptive shell controls, resizable panes, improved macOS window chrome, and smoother embedded reader transitions.
- Added a much richer reader experience with code highlighting, language detection, line numbers, search highlights inside code blocks, math rendering, safer HTML normalization, trusted media handling, image error placeholders, and smarter chunked rendering for long articles.
- Added the new Appearance settings area with dynamic color support, reader theme controls, custom font stacks, reading width presets, code block appearance controls, and searchable settings.
- Added Google Reader-compatible account support, including provider profile detection, account editing, subscription sync, read/star action replay, batch operations, and safer remote state reconciliation.
- Improved subscription management with a full add-subscription page, feed discovery previews, better category handling, and scoped refresh actions for feeds and categories.
- Added app update discovery for GitHub-distributed builds, including release metadata generation, in-app update checks, localized release notes, and a shared update dialog that opens the matching GitHub Release page.
- Added German, Spanish, French, Japanese, Korean, Brazilian Portuguese, Simplified Chinese, and Traditional Chinese localization coverage, plus stronger localization consistency checks.
- Improved reliability across RSS parsing, link normalization, account recovery, cached image metadata, AI cache data, reading progress, auto refresh, outbox recovery, and Android release networking.
<!-- /update-notes:en -->
